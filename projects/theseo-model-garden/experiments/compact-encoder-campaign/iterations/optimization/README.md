# Optimization sequence

Role: compact-code search and architecture refinement
Status: complete
Predecessor: engineering screens

This family contains successively authorized optimization and diagnostic studies.
Post-hoc diagnosis is explicitly exploratory; it is not a frozen selection protocol.
Later diversity, readout, reconstruction, and structured-code studies are successor
protocols rather than silent edits to the first search.
