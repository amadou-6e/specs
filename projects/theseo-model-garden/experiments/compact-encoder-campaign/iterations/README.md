# Compact-encoder iterations

## Contained elements

```text
iterations/
├── 1 README.md
├── 1 engineering-screens/
├── 1 optimization/
├── 1 qualification/
└── 1 collision-readout/
```

These folders consolidate related sub-experiments for migration. They are ordered
families rather than four interchangeable reruns of one recipe. Each local record
states the inherited protocols, execution boundary, outcome, and evidence identities;
legacy files remain immutable provenance.

| Order | Iteration family | Relationship |
| ---: | --- | --- |
| 1 | [Engineering screens](engineering-screens/README.md) | Establishes prerequisite execution and learnability controls. |
| 2 | [Optimization](optimization/README.md) | Uses the screens to authorize compact-code searches and diagnoses. |
| 3 | [Qualification](qualification/README.md) | Replicates and stress-tests the retained compact encoder. |
| 4 | [Collision readout](collision-readout/README.md) | Freezes that encoder and compares new collision heads on fresh data. |
