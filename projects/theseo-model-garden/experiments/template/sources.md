# Consolidated sources

Group sources by governing specifications, implementation revisions, datasets and
worlds, generated artifacts, external literature, and related experiments. For every
source record its stable identity or revision, role, authority, provenance, access or
retention location, and limitations. A mutable path or branch may aid discovery but
does not replace a pinned identity.

Explicitly list unavailable evidence and unresolved provenance. Do not turn example
configuration files, implemented features, issue descriptions, or chat recollections
into proof that an experiment ran.
