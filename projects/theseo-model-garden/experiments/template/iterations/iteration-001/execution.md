# Execution record

Record protocol, code, dependency, data, and artifact identities; commands; hardware;
timestamps; failures; reruns; resource consumption; and every deviation from the
frozen protocol. Distinguish planned behavior from what actually happened.

At minimum include start and end time, exact command, code and protocol revisions,
dependency lock identity, configuration identity, input/world/task identities, seeds,
initial checkpoint, hardware, output locations, and final termination reason. Mark
unknown values as unavailable rather than reconstructing them from expectation.
