# Relocated direction-finding preregistration

> This entry is a historical compatibility record and is not an authoritative
> specification. Follow the current experiment links below for active ownership.

## Archived material

This path formerly identified the preregistration for the voxel-encoder
direction-finding pilots. Other preserved perception-encoder records still link to
that historical filename, so this compatibility record remains at the original
relative location instead of silently redirecting those links to unrelated material.

## Why it was archived

The preregistration was moved into the structured
[Perception encoder R0 experiment](../../experiments/perception-encoder-r0/README.md),
where its protocol, iterations, sources, and outcome can be interpreted together.
This legacy path therefore no longer owns or amends the experiment contract.

## Authority ended

Authority at this path ended when the direction-finding material was reorganized
under `experiments/perception-encoder-r0/`. The exact migration commit has not been
recorded in this compatibility page; Git history remains the source for that
provenance.

## Current replacement

- The active experiment owner is the
  [R0 experiment entry](../../experiments/perception-encoder-r0/README.md).
- The preserved broad pilot preregistration is
  [preregistration.md](../../experiments/perception-encoder-r0/preregistration.md).
- The canonical R0-specific frozen contract is
  [protocol.md](../../experiments/perception-encoder-r0/protocol.md).

Where the broad preregistration and the R0-specific contract differ, the experiment
entry states that the R0-specific contract governs R0.

## Continuing evidential value

This record preserves resolution of the historical
`perception-encoder-pilots.md` path used by archived execution, local-geometry, and
compact-optimization documents. It lets readers follow those provenance links to the
relocated preregistration without treating this compatibility page as current
guidance.
