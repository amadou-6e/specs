# Relocated encoder certification plan

> This entry is historical and is not an authoritative specification.

## Archived material

This path formerly identified the standalone voxel-encoder pretraining and
certification plan. It remains as a compatibility record for historical links that
refer to `legacy/python/perception-encoder-pretraining.md`.

## Why it was archived

The plan is now maintained with the model registry contract, which owns checkpoint
qualification, publication status, and certification evidence. Keeping a second
copy here would allow the two descriptions to diverge.

## Authority ended

The exact migration date and governing release were not recorded in this relocation
stub. New work must not treat this path as authoritative.

## Current replacement

Use [the model-registry certification contract](../../subsystems/model-registry/contract/certification.md)
for the current proposed qualification protocol and its links to active experiments,
research, and architecture ownership.

## Continuing evidential value

This record preserves the former path so old experiment notes, reviews, and artifact
provenance can be interpreted without silently rewriting their historical references.
