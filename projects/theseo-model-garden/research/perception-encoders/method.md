# Research method

## Questions

- Which representation families were considered for scalable voxel perception?
- Which constraints and evaluation criteria did the predecessor document identify?
- Which candidate and next experiment did it recommend?

## Non-questions

This migration does not determine whether cited papers support the predecessor's
interpretations, whether the proposed encoder is feasible, or whether it qualifies
for Model Garden publication.

## Search strategy

The original search dates, databases, queries, browsing paths, inclusion criteria,
exclusion criteria, and access restrictions were not recorded. This migration did not
reconstruct them. It used only the predecessor document already present in the specs
repository.

## Inspection method

The full predecessor document was read and retained as source S-001. Its substantive
claims were separated into bounded finding records. Linked papers, repositories,
issues, code, and experiment artifacts were not independently inspected as part of
this migration.

## Evaluation method

Findings are classified as historical project calculations, requirements,
inferences, or recommendations. Confidence describes confidence that the predecessor
made the recorded claim, not confidence that the claim is externally true. Conflicts
and external validity cannot be assessed without a source-by-source refresh.

## Limitations

The evidence base currently has one internal historical source with many embedded
citations but no preserved per-citation inspection trail. Access dates, reviewed
sections, reproduction work, and content hashes are unavailable. This structure must
not be mistaken for a renewed literature review.
