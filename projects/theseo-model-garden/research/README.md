# Model Garden research

Research here covers representation-learning sources and cross-experiment findings.
It does not define a frozen experimental protocol or promote an artifact.

## Contained elements

```text
research/
|-- 1 README.md
|-- 1 SKILL.md
|-- 1 template/
`-- 0..* <topic>/
```

Each topic is a multi-file entry containing a reproducible method, individually
characterized sources, bounded findings, and synthesis. Copy
[template/](template/README.md), rename the copy, and apply [SKILL.md](SKILL.md).
The single-file records below predate this structure and remain migration inputs until
they receive substantive review; they are not alternative templates.
