# Theseo World Providers

Theseo World Providers is an optional downloadable addition that discovers provider
plugins, acquires external sources, converts or generates voxel worlds, verifies
routing bundles, and exposes accepted bundles to consumers. It does not own the
compiled-world runtime or episode lifecycle in Theseo Anysearch.
