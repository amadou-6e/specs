# Research method

## Questions

- Does the source provide geometry, tasks, observations, references, or a combination?
- Was the material directly inspected or only described by its publisher?
- What must be built or verified before it is usable by Theseo?

## Search and inspection method

This registry extracts material already characterized in the routing environment and
asset inventories reviewed on 2026-09-13. Those inventories searched benchmark sites,
repositories, publications, dataset records, and locally available ignored artifacts.
Individual records preserve whether files or source code were actually inspected.

## Evaluation method

Each source is assessed for task completeness, 3D movement, geometry accessibility,
physical scale, route/reference semantics, licensing, conversion requirements, and
independent validity checks. Upstream tasks and Theseo-derived tasks remain distinct.

## Limitations

This migration does not repeat downloads, rights review, or runtime verification.
Claims retain the evidence boundary of the originating inventories. Source freshness
must be rechecked before an experiment freezes a protocol.
