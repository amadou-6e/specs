# Training runbook

## Purpose and prerequisites

State the supported workflow, required software, hardware, credentials, artifacts, and
preflight checks.

## Procedure

Give deterministic commands and checkpoints for starting, monitoring, stopping, and
resuming the workflow. Link canonical configuration instead of reproducing its schema.

## Expected signals

List health indicators, metrics, logs, artifact locations, and resource expectations.

## Failure and recovery

Describe common failure modes, safe diagnostics, recovery, and escalation boundaries.

## Verification and maintenance

State how the operator confirms success, when the runbook was last exercised, and
which concern-specific operational pages it composes.
