# Policy-explainability contract

## Contained elements

```text
contract/
├── 1 README.md
└── 1 interfaces.md
```

The contract owns explained checkpoint and state identities, model inference path,
selected action score, feature groups, baselines/backgrounds, action comparisons,
algorithm-specific targets, and explanation artifact schema.

See [RLlib explainability](../../../rllib/explain/README.md).
