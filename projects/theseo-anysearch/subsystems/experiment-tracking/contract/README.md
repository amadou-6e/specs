# Experiment-tracking contract

## Contained elements

```text
contract/
├── 1 README.md
└── 1 configuration.md
```

The contract owns run identity, experiment/iteration association, parameter logging,
metric names and steps, artifact references, failure behavior, local/offline operation,
and the distinction between authoritative artifacts and searchable indexes.

See [MLflow tracking](../../../python/mlflow-tracking.md).
