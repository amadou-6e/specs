# Procurement forms

Order confirmation, invoice, receipt or booking. Merchant order reference groups sources. Vinted receipt-only procurement does not invent a transaction.

Follow the [shared representation contract](../../representations/contract.md) for native IDs, source locations, field assertions, hashes, extraction versions and review states.

## Declared associations

Direct forms: None; this object is identified or derived from evidence.

Evidence forms: email, pdf, image, calendar.

Metadata owns these associations. A source document identifying an account does not become the account itself.
