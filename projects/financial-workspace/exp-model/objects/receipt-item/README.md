> One printed or extracted line on a non-income-statement Receipt.

Each Receipt item belongs to one Receipt. It preserves the original label, source locator, role and any printed quantity or amount. A reviewed link can identify the Single expense item described by that line. An Income statement item is the separate line type for an income-statement Receipt.
