This folder demonstrates the proposed Google Drive structure.

Representative original PDFs were copied into the local example during drafting, but they are intentionally excluded from the specs repository and PR. The committed specification uses the proposed filenames and verified Drive links without publishing source documents. Generated JSON, CSV, XLSX, extracted text, Markdown reports, reconciliation outputs, and Notion exports are also outside this example.

The local tree also contains empty directories for recurring spending, receipt images, employment, investments, and tax. Their proposed filenames are documented in ../financial-structure.md because suitable originals are not currently available locally.

The live Financial Workspace contains two native Google Docs: [Workspace links](https://docs.google.com/document/d/14-h2WwcFpFYKDVveGAspKcE4eK-cGz1pRp8R4f1TqUo/edit) links to verified purchase and travel folders, and [README](https://docs.google.com/document/d/1AtknilGP8OP8VvRN9U08vfABqhC2669euLQ-pjf9tnw/edit) explains the workspace. Native Google Docs are linked here rather than represented as local files. No dedicated Claims folder has been identified.
