"The grid is not a cage. It is a grammar — the rules that let type breathe in the right places."

The editorial design language uses a 12-column grid as a rhythm system, not a mechanical divider. Column lines define where Georgia italic headlines begin, where system-ui body text flows, and where monospace data anchors. The 24px baseline is the vertical grammar that ties them all together.

Every zone in BlogHub maps to a deliberate column span. Sidebars use cols 1–2. Content occupies 3–12. Labels use 3–5, inputs 6–12. Hero copy spans one half, article lists the other. Nothing is placed arbitrarily — if it can't be explained by a column split or baseline multiple, it is wrong.

01

All heights are multiples of 24px

Nav = 48px. Section headings = 48px. Form rows = 48px. Bio / article / provider rows = 72px. Hero = 192px. A single off-grid height breaks vertical rhythm for everything below it.

02

Text zones have padding: 0 — columns do the aligning

Content zones carry no padding. Georgia italic titles start flush at the column left edge. The column line IS the margin. Adding padding moves type off the grid line and breaks the alignment claim.

03

Georgia italic = content · system-ui = chrome · mono = data

Article titles and hero headlines → Georgia italic. Nav, labels, buttons, status text → system-ui. All numbers, tags, timestamps, platform names → ui-monospace. Never mix roles on one element.

04

Non-text elements pin to baseline 2 with padding-top: 24px

Pills, buttons, and status indicators use align-items: flex-start + padding-top: 24px rather than centering. This pins them to the second baseline in a 72px row — aligned with adjacent titles.

05

Baseline overlay (z-index: 9) spans full width above all zone backgrounds

One position:absolute; inset:0 div with z-index:9 inside an isolation:isolate grid. Never applied per-zone — clipping at zone boundaries defeats the continuous horizontal rhythm.

01 — 12-Column Grid · Editorial Type in Place

Three-layer overlay: column bands (z:-1) behind content, baseline grid (z:9) above zone backgrounds, column edge lines (z:10) topmost. Georgia italic headline flush to col 1. System-ui body in cols 1–6. Monospace data. Status column cols 9–12.

04 — Colour Zones · Editorial Palette

nav

Navigation · Dark hero

Near-black shell. Logo and active nav in #f4f2ee. Inactive in #6b6860. Georgia italic hero title in white. Mono kickers in #4a4845.

#111110 · text #f4f2ee · muted #6b6860

bg

Page surface · Sidebar

Warm off-white. Page body, sidebar, label zones. Never pure white — that contrast is reserved for cards and inputs.

--bg #f8f6f2 · --ink #1a1917 body text

white

Cards · Inputs

Pure white signals interactivity. Article cards, form inputs, provider status zones. Subtle lift above bg without shadow.

#ffffff · border --line #dddad4

shade

Active state · Divider rows

Slightly darker than bg. Active sidebar items, section dividers, ruler rows. Active item gets --ink border-left.

#f0ede8 · active border --ink

pub

Published pill · Primary CTA

Ink as filled surface. Maximum contrast. "Live" status pills and primary buttons only. Never used for large areas.

bg --ink #1a1917 · fg #f4f2ee

ready

Ready pill · Connected

Muted green. "Ready" status and connection success. Text #286228 ensures WCAG AA on this background.

bg #d4ead4 · fg #286228

draft

Draft pill · Disabled

Neutral warm grey. "Draft" status and disabled actions. Text --ink3. Never used as a body surface.

bg #e8e5e1 · fg --ink3 #8a887f
