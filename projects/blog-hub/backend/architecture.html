All routes

Method Path Group Summary Notes
GET /health dev Health check Used by Playwright webServer.url
GET /api/articles articles List articles Filters: q, gate, status, platform, page, pageSize, sortBy, sortDir
POST /api/articles articles Create article Body: { title } → 201 + { id, title, createdAt }
DELETE /api/articles articles Delete articles (bulk) Body: { ids[], force? } → 409 if published + force=false
POST /api/articles/{id}/push articles Push drafts to platforms → 202 { jobId }. Simulated: job already done on first poll.
POST /api/articles/{id}/inspect articles Run gate inspection → 202 { jobId }. Gate: pass if wordCount ≥ 500, else warn.
GET /api/jobs/{job_id} jobs Get job status Poll every 2 s. Stop on status=done|error.
GET /api/connections connections List all connections Always returns all 5 (blog + AI) regardless of status.
PUT /api/connections/{id} connections Save API token Body: { token }. Marks status=connected.
DELETE /api/connections/{id} connections Disconnect Removes token, marks status=disconnected.
GET /api/connections/medium/oauth-start connections Get Medium OAuth URL Requires MEDIUM_CLIENT_ID env var. Returns available=false if not set.
GET /api/connections/medium/oauth-callback connections OAuth redirect handler Exchanges code→token, posts postMessage, closes popup.
GET /api/platforms platforms List platform connectivity (legacy) Seed-state only. Use /api/connections for live state.
POST /api/dev/reset dev Reset store Restores articles + jobs to seed. Connections NOT reset.
GET /screens/** static Serve HTML screens FastAPI StaticFiles mount. Covers overview/, settings/, editor/, …
