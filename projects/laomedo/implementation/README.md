# Contributor procedures

Fixed category: README.md, spec-impact.md, spec-migration.md, local-skill-agent-pilot.md
compatibility pointer (1 each), focused cross-project procedures (0..*). No arbitrary
technology partitions or folder-copy mechanism.

- [PR spec impact](spec-impact.md): declaration and review order.
- [Migration mapping](spec-migration.md): paths, retained claims and limitations.
- [Canonical pilot](../experiments/local-skill-agent-pilot/README.md): evidence and pinned reproduction guide.

Procedures link contracts rather than redefine them. Reproducing model-backed trials
requires separate authorization and bounded budget. Writing specs or copying templates
does not grant permission to run models, alter settings or publish private evidence.
