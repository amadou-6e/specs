# Retrospective pilot protocol

Reconstructed from the original 2026-10-01 report and pinned reproduction guide.
Original prospective freeze timestamp is not recorded. This organization is post-result,
not a newly predeclared protocol. No new gates or authorizations are invented.

Recorded question/checks: saved-flow whole-skill execution and native reads/tools,
snapshot-bound restart/resume, independent fresh runs, absent-snapshot rejection,
cancellation and cumulative cap. Controls: pinned skill/runtime; independent workspace
per fresh run; expected thread and post-run hash; held/restored negative snapshot;
host file inspection and matched command IDs. Model/effort: gpt-6-luna/low; cap 4/4.
Exact timestamps/hardware beyond Docker Desktop on Windows and independent replication
are unknown. Permissions were retained from the existing Docker study, not redesigned.

Metrics are categorical outcomes, identities, hashes, partial-event retention and ledger
state. No model quality score, latency target, production security assessment or actual
USD bill was measured. Reported local go remains bounded. Future tests or changed controls
need a separate prospective protocol and authorized budget.
