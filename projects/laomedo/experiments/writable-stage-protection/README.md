# Writable stage protection

[EXP-18](https://github.com/amadou-6e/laomedo/issues/48) requires a reviewed E05 safety protocol before any pinned writable-stage test. This folder is a [protocol draft](protocol.md) for review, not a tested protection claim. The experiment depends on the [EXP-07 orphan bound](../orphan-lease/README.md). No degraded Docker stage or model call is authorized by this draft.
