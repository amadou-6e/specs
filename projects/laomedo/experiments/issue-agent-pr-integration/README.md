# Issue to agent to PR integration

[EXP-19 #49](https://github.com/amadou-6e/laomedo/issues/49) asks for an issue-to-agent-to-PR run. The [protocol](protocol.md) preserves the completed credential-free phase zero and defines a separate bounded local test using the existing authenticated Codex runner. The [phase-zero attempt](iterations/2026-10-05/README.md) owns its dated evidence; the [local end-to-end attempt](iterations/2026-10-05-local-e2e/README.md) records six submitted turns, a completed native agent turn, and no verified artifact or publication. Neither phase completes EXP-19's published-PR criterion.

The [artifact retry](iterations/2026-10-05-artifact-retry/README.md) retains that negative finding and the cumulative ledger while testing a corrected source fixture under a separate four-turn grant. It observed a completed Langflow report and exact host publication in [draft PR #71](https://github.com/amadou-6e/laomedo/pull/71). This establishes the bounded single-user local path, with direct agent push, hosted/multi-user isolation and production authentication still outside the result.
