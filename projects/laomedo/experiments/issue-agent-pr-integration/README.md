# Issue to agent to PR integration

[EXP-19 #49](https://github.com/amadou-6e/laomedo/issues/49) asks for an issue-to-agent-to-PR run. The [phase-zero protocol](protocol.md) deliberately tests only the credential-free handoff among existing Work Graph snapshots, durable run identity, synthetic agent receipts and a local Git PR candidate. It uses no provider, Langflow server, GitHub write, personal login or model turn. The [initial attempt](iterations/2026-10-05/README.md) owns its dated evidence. This phase cannot complete EXP-19's real-agent or published-PR criteria.
