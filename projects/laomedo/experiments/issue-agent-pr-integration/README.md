# Issue to agent to PR integration

[EXP-19 #49](https://github.com/amadou-6e/laomedo/issues/49) asks for an issue-to-agent-to-PR run. The [protocol](protocol.md) preserves the completed credential-free phase zero and defines a separate, prospective bounded local test using the existing authenticated Codex runner. The [phase-zero attempt](iterations/2026-10-05/README.md) owns its dated evidence; the [local end-to-end attempt](iterations/2026-10-05-local-e2e/README.md) remains unexecuted until its inputs and grants are frozen. Phase zero cannot complete EXP-19's real-agent or published-PR criteria.
