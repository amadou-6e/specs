# Laomedo subsystem specifications

This proposed folder collection contains entries owning stable behavioral
boundaries. It belongs to the draft [project structure](../SPECS.md).

The container owns `1 README.md`, `1 template/`, and `0..* <subsystem>/` entries.
Copy template/ directly and rename it. The entry template owns overview, contract,
design and validation; optional interface/configuration/guide pages are introduced
only when their subject exists. Concrete entries begin with draft metadata.

The [run catalogue template](template/README.md) is a populated illustrative
example. It does not assert that Laomedo implements or has accepted that design.
