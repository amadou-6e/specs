# Codex runner isolation, persistence, and settings: initial findings

Status: investigation in progress, 2026-09-29. This publishes no-model probe
structures and the credential gate for [specs issue #120](https://github.com/amadou-6e/specs/issues/120).
Findings will be completed when probes are run against the pinned Codex CLI.

The [Codex Agent component](../components/codex-agent.md) defines the
proposed flow step; [runner isolation](../sandboxing/runner-isolation.md) and
[run traces](../monitoring/run-traces.md) specify shared execution boundaries.
The spike code is at
[`laomedo/experiments/feasibility/120/`](https://github.com/amadou-6e/laomedo/tree/main/experiments/feasibility/120)
and open for review in a Laomedo PR.

The spike reuses #119's skill-discovery results without retest, following the
handoff from [#119](119.md). Only version-specific differences are
investigated against the #119 baseline.

## Pass condition matrix

| Condition | Probe | Status |
| --- | --- | --- |
| 1. Supported model/effort pair recorded as requested and effective | `probe_model_effort.py` | Not yet run |
| 2. No writes to personal Codex profile and no personal skill load | `probe_isolation.py` | Not yet run |
| 3. Private native thread resumes after runner restart from last post-run workspace snapshot | `probe_persistence.py` | Not yet run |
| 4. Raw streamed events contain at least one tool call and matching result | `probe_stream_events.py` | Not yet run; credential gate blocks |
| 5. Unsupported settings and unavailable snapshots fail explicitly | `probe_model_effort.py`, `probe_persistence.py` | Not yet run |

## Probe summary

| Probe | Credential needed | What it tests |
| --- | --- | --- |
| `probe_model_effort.py` | No | model/list completeness, supported/unsupported effort rejection, unknown model rejection |
| `probe_isolation.py` | No | private skill discovery, personal profile comparison before/after |
| `probe_persistence.py` | No | thread/resume after restart, thread/list, missing-workspace rejection |
| `probe_stream_events.py` | Yes (file-backed ChatGPT) | raw item/tool-call/tool-result/usage events, tool call/result linkage |

## Credential gate

No dedicated Laomedo project/service credential was available at writing.
`probe_stream_events.py` includes a credential gate that checks auth mode and
connectivity before any model call. The preflight (`--run` omitted) verifies
fixture discovery, model listing, and connectivity without spending.

If a suitable credential becomes available, run the preflight first, then
`--run`. The limit is USD 20 total spend.

## Reproduction

Requirements: Python 3.9+, Codex CLI binary (pin target version per #119
follow-up). All probes use stdlib only. Running from the Laomedo repository
root:

```powershell
python experiments/feasibility/120/probe_model_effort.py --codex '<absolute-path-to-codex>'
python experiments/feasibility/120/probe_isolation.py --codex '<absolute-path-to-codex>'
python experiments/feasibility/120/probe_persistence.py --codex '<absolute-path-to-codex>'
python experiments/feasibility/120/probe_stream_events.py --codex '<absolute-path-to-codex>' --state-dir '<private-state-dir>'  # preflight
python experiments/feasibility/120/probe_stream_events.py --codex '<absolute-path-to-codex>' --state-dir '<private-state-dir>' --run  # model turn
```
