# Decision template

Copy this file to `<NNNN>-<slug>.md` for a new decision entry.

## Status

`draft`, `active`, `complete`, `deprecated`, or `superseded`.

## Context

State the problem and constraints that made a choice necessary.

## Decision

State the choice made, plainly.

## Alternatives considered

List the rejected options and why each was rejected.

## Consequences

State the resulting benefits, costs, and follow-up obligations.

## Compatibility and migration

State any compatibility or migration effect. `none` is a valid answer.

## Links

Link affected subsystems and experiments.
